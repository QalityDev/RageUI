# RageUI Standalone Resource

Framework de menu NUI RageUI autonome pour FiveM, compatible ESX / OX / Standalone.

## Installation

1. Placez le dossier `RageUI` dans le répertoire `resources` de votre serveur FiveM.
2. Ajoutez `ensure RageUI` dans votre fichier `server.cfg` ou `ressources.cfg`.

## Utilisation

Pour tester le menu en jeu :
- Tapez la commande `/rageui` ou `/menu`.

## Structure

- `client/rageui.lua` : Moteur principal RageUI.
- `client/example.lua` : Menu de démonstration.
- `server/main.lua` : Script serveur.
- `web/` : Interface NUI HTML/CSS/JS.
